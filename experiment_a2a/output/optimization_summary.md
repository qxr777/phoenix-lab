## 教学启示

1. **System Prompt 的隐藏成本**: 每增加 100 tokens 的 system prompt ≈ 增加 ~200ms TTFT
2. **重试是性能杀手**: 3 次自修正重试将单 agent 延迟扩大了 3-4 倍
3. **上下文裁剪是必要的**: 不裁剪的话，reviewer 的 context 会随着 executor 数量线性增长
