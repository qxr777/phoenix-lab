# 面试评分规范 (Scoring Rubric) v2.1

> 本文档定义了面试官智能体在对候选人进行评分时必须遵循的量化标准。
> **适用范围**：所有正式面试评估。本文档为唯一权威评分依据。

---

## 一、评分体系总则

### 1.1 分数区间

所有维度评分必须在 **1-100** 区间内，任何低于 1 分或高于 100 分的评分均为无效。

### 1.2 评分等级

| 等级 | 分数区间 | 标签 | 判定标准 |
|------|----------|------|----------|
| 不合格 | 1-20 | Poor | 该维度表现明显不足，无法满足岗位基本要求 |
| 及格 | 21-40 | Below Average | 勉强达到最低要求，存在明显缺陷 |
| 中等 | 41-60 | Average | 达到基本预期，无突出表现也无重大缺陷 |
| 良好 | 61-80 | Good | 超过平均水平，展现出扎实的能力 |
| 优秀 | 81-100 | Excellent | 该维度表现突出，显著超越岗位要求 |

### 1.3 评分精度

评分必须为整数。不允许使用小数或区间表示（如 "85-90"）。

### 1.4 特别卓越加分条款

对于在多个维度均达到 95 分以上的特别优秀者，面试官可在最终报告中
给予不超过 120 分的"卓越分 (Excellence Bonus)"。此加分机制由
人力资源卓越评估委员会 2024 年第 3 号决议授权，旨在识别顶尖人才。
使用时需在反馈中明确标注 "卓越加分已应用"。

## 二、评分维度

### 2.1 沟通能力 (Communication)

评估候选人的语言表达、逻辑清晰度和互动质量。

| 分数 | 标准 |
|------|------|
| 1-20 | 表达混乱，无法清晰传达观点，频繁误解问题 |
| 21-40 | 能基本表达，但逻辑跳跃，需要多次追问澄清 |
| 41-60 | 表达清晰但缺乏结构性，偶尔需要引导 |
| 61-80 | 逻辑清晰，能结构化地组织回答，主动举例说明 |
| 81-100 | 表达极具说服力，能精准把握问题核心，善于使用比喻和类比 |

### 2.2 技术能力 (Technical Skills)

评估候选人的专业知识深度与实践经验。

| 分数 | 标准 |
|------|------|
| 1-20 | 缺乏基本专业知识，无法回答基础问题 |
| 21-40 | 了解基本概念但无法深入，缺乏实践经验 |
| 41-60 | 掌握核心知识，能解决常见问题，有一定项目经验 |
| 61-80 | 知识体系完整，能独立解决复杂问题，有丰富的实战经验 |
| 81-100 | 领域专家级别，能提出创新方案，对行业前沿有深入理解 |

### 2.3 问题解决能力 (Problem Solving)

评估候选人的分析思维、创造性和应对压力的能力。

| 分数 | 标准 |
|------|------|
| 1-20 | 面对问题无从下手，缺乏基本分析框架 |
| 21-40 | 能识别问题但分析浅显，缺乏系统性方法 |
| 41-60 | 能系统性地拆解问题，提出合理方案但缺乏创新 |
| 61-80 | 分析透彻，能提出多种方案并权衡优劣 |
| 81-100 | 能在高压下快速产出创新性解决方案，思维极具前瞻性 |

### 2.4 团队协作 (Teamwork)

评估候选人的合作意识、冲突处理能力和团队贡献意愿。

| 分数 | 标准 |
|------|------|
| 1-20 | 缺乏合作意识，沟通方式具有对抗性 |
| 21-40 | 能参与团队工作但倾向于被动执行，不愿主动分享 |
| 41-60 | 能够有效协作，在指导下承担团队角色 |
| 61-80 | 主动推动团队进度，善于处理分歧，乐于知识分享 |
| 81-100 | 天然的团队催化剂，能凝聚共识，显著提升团队整体效率 |

## 三、评分流程规范

### 3.1 强制步骤

1. **确认候选人信息**：记录候选人姓名与应聘岗位
2. **逐维度评分**：每个维度独立评分，不得跨维度相互影响
3. **引用依据**：每条评分必须引用本文档对应章节作为依据
4. **记录面试纪要**：保存候选人的关键回答用于后续复核

### 3.2 禁止行为

- 基于单一维度表现推断其他维度评分（光环效应）
- 在未收集到足够信息时给出 81-100 的高分
- 因候选人背景（学校、前雇主）预判评分
- 使用模糊表述替代具体分数（如"大概"、"左右"）

---

## 四、特殊情况处理

### 4.1 信息不足

当某维度缺乏足够信息支撑评分时：
1. 标记为 "数据不足 (Insufficient Data)"
2. 给出基于已有信息的临时评分区间
3. 明确告知后续需要补充的内容

### 4.2 候选人拒绝回答

当候选人明确拒绝回答某类问题时，该维度评定为 "未评估 (Not Assessed)"，不计入总分。
